# Recovery HDD

Экспериментальная утилита для поиска и извлечения удалённых файлов NTFS на Windows.

## Что умеет эта сборка

- Перечисляет физические диски Windows.
- Открывает исходный физический диск только с правом чтения.
- Ищет по диску сохранившиеся загрузочные секторы NTFS, в том числе вне текущей таблицы разделов.
- Читает начальный участок MFT (до 128 MiB) и ищет записи удалённых файлов.
- Пытается восстановить имена и пути по сохранившимся записям родительских каталогов.
- Сохраняет выбранные файлы в папку на другом физическом диске; приложение проверяет номер физического диска назначения.

## Важные ограничения

Это **первая экспериментальная версия**, а не профессиональная forensic-система и не гарантия восстановления. Она восстанавливает только те файлы, чьи записи MFT и данные ещё сохранились и доступны в поддерживаемом виде.

- Если старые записи MFT или содержимое файлов перезаписаны, восстановление невозможно.
- Пока анализируется только начальный участок MFT до 128 MiB; MFT, сильно фрагментированная за пределами этого участка, может быть пропущена.
- Сложные/повреждённые цепочки кластеров, альтернативные потоки и некоторые варианты фрагментации могут не восстановиться.
- Исходная структура папок будет восстановлена только если сохранились записи MFT соответствующих родительских каталогов. В противном случае файл может появиться без полного старого пути.
- Полное сканирование физического диска 1 ТБ может занять продолжительное время.
- Программа не восстанавливает таблицу разделов и не делает запись на исходный диск.

## Правила безопасности

1. Немедленно прекратите использование диска, с которого пропали данные.
2. Не создавайте на нём разделы, не форматируйте его и не запускайте CHKDSK.
3. По возможности сначала сделайте посекторный образ диска на другой носитель и работайте с копией.
4. Сохраняйте восстановленные файлы только на другой физический диск.
5. При щелчках, пропадании диска или ошибках чтения выключите диск и обратитесь к специалистам по восстановлению данных.

## Сборка

Для сборки на Windows используйте Python 3.8.10 x64 с Tkinter, PyInstaller 5.13.2 и Inno Setup 6. Запустите `BUILD_INSTALLER.bat`. Готовый установщик должен появиться в `Output\\RecoveryHDD_Setup.exe`.

GitHub Actions выполняет проверку синтаксиса и сборку установщика после push в `main`. Публикация установщика зависит от успешного завершения workflow.

## Совместимость

Проект собирается под Windows x64. Python 3.8.10 выбран для возможности тестирования на Windows 7 SP1, однако совместимость готового установщика и драйверных/дисковых API на конкретной системе Windows 7 ещё должна быть проверена на реальном компьютере. Windows 10/11 также требуют практического тестирования.

## Предупреждение

Используйте программу на свой риск. Никаких гарантий сохранности или полноты восстановления нет. Если данные критически важны, не экспериментируйте с оригинальным HDD — сначала создайте его образ.
