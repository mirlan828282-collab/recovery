# Recovery HDD

Первая безопасная версия утилиты для диагностики дисков Windows и поиска признаков старых разделов NTFS.

## Важно
- Программа открывает физические диски **только для чтения**.
- Ничего не форматирует, не исправляет таблицы разделов и не записывает на исходный диск.
- Найденные сигнатуры NTFS — это предварительные кандидаты, а не гарантия восстановления файлов.
- Для восстановления данных потребуется отдельный этап анализа NTFS MFT и извлечения файлов. До него не используйте программу для записи/восстановления на исходный диск.
- Сохраняйте любые восстановленные данные только на другой физический диск.

## Сборка
Для целевой совместимости со старыми Windows используется Python 3.8.10 x64 и PyInstaller 5.13.2. Запустите `BUILD_INSTALLER.bat` на Windows с установленным Inno Setup 6. GitHub Actions собирает установщик автоматически после push в main.

## Запуск
Запустите программу от имени администратора, чтобы Windows разрешила чтение физических дисков. Выберите диск и нажмите «Проверить». На первом этапе проверяются MBR/GPT и сигнатуры загрузочных секторов NTFS.

## Ограничения первой версии
Эта версия выполняет только безопасную диагностику разметки и NTFS boot sectors. Она пока **не восстанавливает каталоги и файлы** и не меняет таблицу разделов. Поиск старых MFT и построение исходного дерева каталогов — следующий этап разработки.
